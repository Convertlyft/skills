# Site audit playbooks

Each section is one to-do's steps. A to-do on the What to do page names its section by id.

### PB-AUDIT-CRAWL-MORE — The crawl found more to fix

**When:** The latest crawl lists issues across a number of pages.

**Do:**
1. Open the list of issues on the SEO page, Pages tab; each one names the pages it is on and what to change.
2. Start with issues on the pages that bring the most visits or results.

**Check after:** The issue count on the next crawl.

### PB-AUDIT-CRAWL-PROBLEM — One crawl issue on several pages

**When:** One kind of issue appears on several pages in the latest crawl.

**Do:**
1. Fix the issue on the pages it lists.
2. If it comes from a shared template, fix the template once.
3. Run the crawl again to confirm.

**Check after:** That issue on the next crawl.

### PB-AUDIT-CRAWL-STALE — The last crawl is old

**When:** The latest full crawl is old enough that the site has likely changed since.

**Do:**
1. Run a new crawl from the SEO page.

**Check after:** The date of the latest full crawl.
