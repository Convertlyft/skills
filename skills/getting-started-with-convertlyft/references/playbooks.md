# Getting started playbooks

Each section is one to-do's steps. A to-do on the What to do page names its section by id.

### PB-START-SEO — Search is not set up yet

**When:** The site has no tracked searches and no crawl yet.

**Do:**
1. Set up tracking for the searches the business cares about on the SEO page.
2. Run a first crawl from the same page.

**Check after:** Tracked searches and a crawl appear on the SEO page.
