# Convertlyft API reference

Generated by `node scripts/check-drift.mjs --write` from the live server:
MCP `tools/list` at `https://mcp.convertlyft.com/mcp?features=all`, `https://convertlyft.com/.well-known/convertlyft-capabilities.json` and `https://convertlyft.com/openapi.json`.
Do not edit by hand; CI fails when this file and the live server disagree.

MCP endpoint: `https://mcp.convertlyft.com/mcp` (protocol 2025-11-25).
REST: `https://convertlyft.com`, header `Authorization: Bearer cvl_pat_…`. GET arguments go in the query string, POST arguments in a JSON body.
Timestamps: strict ISO 8601 with a zone.

A tool marked "via `cvl_call_read`" is not in the default tool list: find it with `cvl_search_tools` and run it with `cvl_call_read`.
